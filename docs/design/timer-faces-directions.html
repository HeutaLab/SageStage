Art style — the same scene, three treatments

One motif (the alien, mid-tiptoe, stage 6-ish) rendered three ways. The pick decides the art pipeline and whether we vendor a library. Faces and the game can use different registers — a drawn game and toy-object faces is not a clash, it's each surface speaking natively. Decided 2026-08-03, Glenn live: S1 pen for Escape! (rough.js) + S2 toy for the faces. S3 parked.

S1
Teacher's pen. Wobbly ink, hachure shading, tint used sparingly — the game literally draws like a teacher at the whiteboard, and the colleague's Draw Pad doodles were the brief. Library: rough.js — MIT, ~9 KB, one vendored file, seeded wobble. ✓ picked for Escape!
S2
Soft Daylight toy. Plush shapes, thick friendly outlines, app tints baked in — matches the widget chrome and stays crisp at the 150 px floor. Library: none — bespoke SVG/canvas; optional Kenney CC0 packs as tracing bases. ✓ picked for the timer faces
S3
Paper cutout. Flat torn-edge shapes, no outlines, shadow offsets — echoes the HeutaLab collage heritage. Boldest and most ownable; busiest at small sizes, so it needs a motion test before committing a whole game to it. Library: none — bespoke. parked — revisit if a brand-echo surface ever wants it
