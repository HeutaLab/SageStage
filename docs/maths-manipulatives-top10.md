# Top 10 maths manipulatives — White Rose Maths

Roadmap for the Maths widget section. Ranked by how widely each resource is used
across the White Rose scheme, based on the official TTS × White Rose Education
"Maths Essentials" kits (KS1 and KS2) and the representations that appear
throughout the schemes of learning. The White Rose core list is number-heavy by
design — shape tools sit in the honourable mentions.

Status key: ✓ built · ◐ partly covered · ○ to build

| # | Manipulative | Teaches | Status in Sage |
|---|-------------|---------|----------------|
| 1 | **Ten frame + two-colour counters** | Number bonds, subitising, addition/subtraction within 10/20, place value | ✓ `counters` (+ `frametiles` for number-shape tiles) — loose red/yellow counters: tap to place, tap to flip, drag to move, drop on the bin (or off the mat) to remove; mats for plain / ten frame / 20 frame / part–whole circles / array grid with snap-to-cell (spares sit loose — "ten and a bit"); Flash + Cover for subitising; auto sentences count only counters ON the grid (red/yellow bonds, array ×÷ family, part–whole regions) — spares beside the frame stay out of the sum; everything scales with the widget |
| 2 | **Base 10 (Dienes)** | Place value, exchanging, column addition/subtraction, Y1–Y5 | ✓ `dienes` — ones / tens rods / hundred flats / thousand cube on a plain mat or T·O / H·T·O / Th·H·T·O charts with live count badges; tap a column or the tray to add, drag to move, bin to remove; ten-of-a-kind glows a "10 ⇄ 1" chip that converge-animates the exchange, and a block dropped on a lower column (or double-tapped) breaks into ten — dropping on a higher column bounces with a "collect ten first" nudge; value pill with tap-to-mask "?" (the sentence scaffold stays visible and holds back only the answer — "… = ?"), stem sentence + expanded form + exchange facts, Flash/Cover for place-value subitising, Build-it challenge with streak, Random mystery number; TTh and seven-column Millions charts for Y5+ — ten-thousand towers, hundred-thousand slabs and a dominant million cube, with the scale gently compressed (marked "not to scale") so ones–thousands stay visible and grabbable; whole kit scales with the widget |
| 3 | **Place value counters + chart** | Place value from millions to thousandths, all four column methods — the KS2 workhorse | ✓ `pvcounters` — same-size labelled counters (rainbow-ramp colours per place, like the physical sets) from millions down to thousandths; charts from T·O to a seven-column Millions chart plus O·t·h and a six-column Decimals chart with the decimal point on the header line; tap a column or the tray to add, drag to move, bin to remove; ten-of-a-kind glows a "10 ⇄ 1" chip that converge-animates the exchange — across the decimal point too (1 one ⇄ 10 tenths); drop on a lower column or double-tap to break into ten; ×10 / ÷10 slide every counter one place ("the counters move, the point stays put"); value pill with tap-to-mask "?", stem sentence + expanded form + exchange facts, Flash/Cover, Build-it challenge with streak, Random mystery number, optional fraction labels (1/10) on decimal counters; whole kit scales with the widget |
| 4 | **Part-whole model** | Partitioning, number bonds, fact families, inverse operations — the signature WRM diagram | ✓ `partwhole` — cherry diagram with 2–6 parts, whole always the truthful sum (or teacher label), mystery "?" boxes with tap-to-reveal, WRM-style counters inside circles (colour-split in the whole, neutral when a part is hidden so nothing leaks), tap-to-count (tap the selected part to count counters in one at a time — the whole's dots compound live; "−" takes away, down to 0 for zero bonds), four orientations, fact family strip, fit-to-widget scaling (drag the widget corner to scale the whole model), presets (bonds to 10, counters, missing part/whole, three parts, tens & ones, all hidden) |
| 5 | **Bar model** | Problem solving, fractions of amounts, ratio, algebra — WRM's other signature model | ✓ `barmodel` — full WRM treatment: discrete unit boxes → continuous bars, part–whole/comparison/before–after/equal-parts/fractions/equal-fractions/ratio presets, drag-to-resize, mystery boxes, whole/difference/sub-brackets, part labels, fraction shading, auto number sentences (fact families) |
| 6 | **Number line (marked and blank)** | Counting, rounding, fractions/decimals on a line, empty-line calculation strategies | ✓ `numberline` — marked scales from 0–10 to 0–1,000 plus decimal, fraction (halves/quarters/thirds, shown as ¾ or 0.75) and negative lines, minor ticks, and a fully blank empty number line; press-and-drag draws jump arcs that snap to ticks and label themselves ("+10") or take a typed label, taps drop landing dots (marked) / editable marks (blank), labels cycle all / ends / hidden for counting-on work, and Facts reads the jumps in drawing order as a sentence ("36 + 10 + 10 + 3 = 59"); custom from/to/step in settings; (`frametiles` keeps its tiles-on-a-line mode for number-shape work) |
| 7 | **Rekenrek** | Subitising, bonds, doubles, bridging ten — heavily promoted by WRM (1-Minute Maths app, free booklet series) | ✓ `rekenrek` — 10, 20 (default) and 100-bead racks, five red + five white per row resting on the right; tap a bead to bring it and every bead before it across in one push (tap a shown bead to send it and the rest home), or drag and the row glides as you cross the middle; value pill with "?" mask, sentences (row sums, doubles, bonds to 10/20, "3 tens and 4 more" on the 100), Flash/Cover subitising, show-me-a-number challenge with streak, Random mystery push; whole rack scales with the widget |
| 8 | **Bead string (0–100)** | Counting in 1s/10s, bridging, complements to 100 — 10 per official kit | ○ |
| 9 | **Interlocking cubes (multilink)** | Counting, comparison, early addition, measure, 3-D shape — 1,000 per kit | ○ |
| 10 | **Cuisenaire / number rods** | Number sense, fractions, ratio, proportion, algebra; concrete bridge to bar models | ○ |

## Already covered elsewhere in Sage

- **Teaching clock** (`teachclock`) — time.
- **Money tray + Class shop** (`moneytray`, `shop`) — money.
- **Number shapes (Numicon-style)** (`frametiles`) — odds/evens, bonds, parity;
  ranks alongside the top 10 (in both official kits as "number frames") and is
  already built.
- **Dice** (`dice`) — in both kits as part of the games/fluency strand.

## Next five (honourable mentions)

- **Digit cards (0–9)** — in both official kits; place value games, target numbers.
- **Number balance** — KS1 kit; equality and the `=` sign as balance.
- **Hundred square** — used throughout KS1 schemes; patterns, +10/−10 jumps.
- **Gattegno chart** — used in WRM training videos for place value and powers of 10.
- **Geoboard + pattern blocks** — the shape strand: 2-D shape, symmetry, angles,
  fractions of shapes. Not in the number-focused kits but used pictorially in
  WRM geometry blocks.
