## 3. THE TRAP THAT COST THE EVENING

**There are two CSPs.** One in `src-tauri/tauri.conf.json`, one as a
`<meta http-equiv="Content-Security-Policy">` in `index.html`. A browser enforces
both and applies the intersection, so the stricter wins and editing one silently
achieves nothing. The comment above the meta tag says "Keep the two in step
directive by directive". It was not heeded.

Four diagnostics returned nothing and every absence looked like innocence: the
asset protocol logs refusals through `log`, and the app installs no logger; a CSP
block happens in the renderer so no request reaches Rust at all; `assetUrl`
returned `''` on every failure path; and `strings(1)` over the binary gave
confident false answers **twice** — Tauri brotli-compresses embedded assets, and
it embeds the whole ACL manifest regardless of what is granted.

**What ended it: a `securitypolicyviolation` listener.** Its event carries
`originalPolicy` — the policy WebKit is *actually* enforcing. One line, and the
whole hypothesis space collapsed. Reach for that immediately next time.

   anywhere in the report. The suspect is `storage.js`'s `onCloseRequested`: when

   `destroy()` — so the window is torn down inside the continuation of a WebKit
   callback. That sequence has existed for a while but only ever on the main
   window; running it on a pop-out is new as of `a0bb4fb`, and this is the only
   crash report on the machine ever.
   **Repro attempt:** open a pop-out, change something in it (dirty queue), close
   with ✕, five times. **Likely fix if it reproduces:** defer the `destroy()` to
   a fresh task so WebKit unwinds first. Not applied — speculative without a
   repro, and it is a teardown path that handles unsaved work.

**3. `org.sagestage.app` ends in `.app`.** Tauri warns it collides with the macOS
   bundle extension. Free to change now, expensive once anything is signed and
   distributed. Decide before the first signed installer.
